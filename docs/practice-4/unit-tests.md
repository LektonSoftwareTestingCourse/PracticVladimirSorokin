# Практика 4. Unit-тесты

| Сервис | Проверки |
|---|---|
| Gateway | Валидация платежа, лимит запросов, открытие и восстановление circuit breaker |
| Switch | BIN, нормализация идентификаторов, маршрутизация, ошибки HTTP-клиентов, публикация и откат |
| Authorization | Статусы карты, баланс, срок действия, лимиты, конфликт записи usage, ошибки БД и rollback |
| Card Management | Резерв и возврат, повторный резерв, пагинация, алгоритм Луна |

Зависимости заменены моками. `MockRestServiceServer` подменяет ответы HTTP-клиентов
в памяти; серверы, PostgreSQL и RabbitMQ для этого набора не нужны.
Время в Authorization зафиксировано, в Gateway используются управляемые часы и ticker.

Запуск из корня проекта:

```shell
mvn -f services/pom.xml -P gateway,switch,authorization,card-management clean verify
```

JaCoCo сохраняет HTML и XML в `services/<сервис>/target/site/jacoco/`.
Для Switch проверяется покрытие ветвей всего модуля не ниже 70%, без исключения классов.
CI запускает тесты и загружает четыре отчёта как `jacoco-report-<сервис>`.

Локальная проверка: 116 тестов, без ошибок и пропусков. Switch: 61 из 72 ветвей — 84,72%.
Первый GitHub Actions завершился на поиске Checkstyle в отдельном шаге линтера.
Проверка стиля перенесена в штатный `verify`; добавлен `-U` для повторной проверки
недостающих зависимостей. Задания матрицы больше не отменяют друг друга при одной ошибке.
Исправленный workflow требует нового удалённого прогона после публикации коммита.
